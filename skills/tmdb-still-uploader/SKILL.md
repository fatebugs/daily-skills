# TMDB 分集剧照上传

只处理已有 TMDB 分集的图片上传。创建分集、补齐编号、修改标题日期和时长由独立的分集管理 skill 处理。

## 确定范围与文件映射

先确认剧集、季、起止集数、本地图片根目录以及已处理集数。扫描本地目录或图片文件名，建立“TMDB 集号 → 精确图片路径”的映射。

- 从文件名或所在目录解析集号，使用数字匹配和明确的标题规则，不按文件排序猜集数。
- 一集只能选择其对应图片；缺图、重复候选、无法解析或范围外文件分别列出。
- 先检查当前 TMDB 是否已有剧照。已有目标图片应跳过，避免重复上传；不能因为本地存在图片就假定 TMDB 已上传。
- 保留图片扩展名和原文件，上传流程不修改、移动或删除本地图片。
- 长批次保存进度：已确认上传、已跳过、缺图、失败、待重试和最后确认时间。

## 逐集上传

在当前 TMDB 分集编辑页面按顺序处理：

1. 打开目标分集的图片区域，确认当前集号和标题。
2. 点击添加图片，选择映射到该集的本地图片。
3. 等待上传控件或图片列表出现明确的成功状态，例如 `Uploaded` 或新的图片条目。
4. 如有上传弹窗，点击右上角关闭，回到当前分集详情。
5. 成功确认后再点击下一集或导航到下一个目标。

每次页面变化后重新获取当前页面状态，不复用旧的元素编号、截图坐标或文件选择器状态。上传条目偶尔延迟显示时等待列表出现后再继续，避免重复提交。

大尺寸图片如果触发网站的手动确认或安全提示，按页面提供的确认步骤处理，并记录该集结果。确认失败、权限不足或上传状态不明时暂停当前集，先检查页面和进度，不连续点击。

## 语言设置

图片语言设置是可选步骤。只有用户明确要求时才修改，例如选择 `zh-CN`；用户要求跳过时保持默认值。语言修改成功与图片上传成功分别记录，不能因为图片上传成功就声称语言已设置。

## 本地文件访问与节奏

网页上传需要浏览器扩展能够访问本地文件。若文件选择器被权限阻止，明确提示用户在浏览器扩展详情中启用“允许访问文件网址”，不要绕过权限或改用未授权的传输方式。

为减少账号风控和重复请求：

- 尽量在同一个分集编辑页面连续处理，避免反复打开来源页面。
- 优先使用已经取得的图片映射和页面列表信息。
- 每完成一小批保存进度，遇到页面异常先停在当前集。
- 第一次操作先验证一集的完整上传闭环，再批量继续。

## 结果报告

最终简要说明实际上传范围和数量，并分别列出跳过、缺图、失败或结果不明的集数。只有看到上传成功后的图片条目，才计为已完成。若用户只要求补图，不附带创建分集、改名或完整图片质量审查。
